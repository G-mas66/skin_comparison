本报告实际使用的定义

Leakage Rate = Test 中患者也在 Train 的图片数 ÷ Test 图片总数

“同患者同标签存在率”按每个 Test 图片判断：在该 Test Fold 之外的 Train 图片中，同一患者是否至少存在一张相同原始 CEA 标签的图片。标签距离是该 Test 标签与同患者 Train 标签之间的最小绝对差值。

如何解释 41.37% 的患者多数标签 baseline？

它是显式知道 patient ID 后的历史标签上限参考，不是 ResNet50 应达到的最低性能。

它说明了什么

  • 41.37% 高于全局多数类 32.73%，所以患者身份确实携带了一定的 severity 信息。
  • 但患者内部标签高度变化，患者 ID 不能稳定决定当前图片的严重程度。
  • 91.37% 的“同患者同标签存在”只是说明 Train 中存在可参考样本，不代表模型一定能从脸部外观中识别患者并正确利用它。

它不能直接说明什么

  • 不能把 41.37% 当作模型应达到的下限；baseline 显式拿到了 patient ID，ResNet50 没有。
  • 不能把 47.19% 的平票宽松结果当作正式 baseline；它是有利于正确答案的乐观上限。
  • 不能写“患者泄漏没有影响”；只能说泄漏机会很大，但未必稳定转化为性能提升。

建议采用的论文表述

这段文字收紧了因果语气，保留当前数据真正支持的结论。

图像级随机划分造成了完全的患者重叠，并且 91.37% 的测试样本能够在训练集中找到同患者、同严重程度的样本，表明非患者隔离设置存在显著的信息泄漏机会。然而，97.56% 的患者具有多个严重程度标签，且基于患者训练历史多数标签的预测准确率仅为 41.37%，仅比全局多数类基线高 8.64 个百分点。这表明患者身份虽然携带一定的严重程度信息，但不足以稳定决定当前疾病等级。因此，患者重叠并未必然转化为明显的分类性能提升，模型仍需要主要依据当前图像中的疾病表型完成严重程度判断。

最终实验定位

患者隔离路线应作为正式泛化性能的主结果，因为它回答的是“遇到完全没见过的新患者是否仍能工作”。Non-isolated 路线适合作为泄漏敏感性对照，而不应作为主性能评估。

  • 当前证据链：100% 患者重叠 → 91.37% 同患者同标签参考 → 97.56% 患者多标签 → 41.37% ID-only 多数标签准确率。
  • 相邻图片存在有限的序列连续性：同标签率比非相邻图片高 7.42 个百分点，但仍不足以让相邻图片直接决定标签。
  • 若比较 Isolated 与 Non-isolated，下一步应直接报告每个 seed 的 Accuracy、Macro-F1、QWK 和差值 Δ = Non-isolated − Isolated。
